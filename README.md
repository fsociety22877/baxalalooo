# 🔥 Baxa Discord Bot - بەخە لالۆ

Advanced Kurdish Discord Bot with AI, Economy, and Moderation features.

## Features

✅ **Moderation**: Mute, Ban, Kick, Warn, Timeout
✅ **Economy**: Coins, Levels, Shop, Inventory
✅ **AI**: Gemini Integration
✅ **Tickets**: Support System
✅ **Auto-Responder**: Custom Triggers

## Setup

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` file with your tokens
4. Run: `python main.py`

## Commands

Type `!commands` in Discord to see all available commands.
